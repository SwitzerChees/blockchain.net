# blockchain.net
A blockchain implementation based on the dotnet standard 2.0

## Projektidee
Die Idee dieses Projekts war es ein Frontend für eine selbst entwickelte Blockchain zu entwerfen.

Das Frontend sollte in Angular gebaut werden und folgende Features enthalten:
* Anzahl Blöcke
* Anzahl Transaktionen
* Letzte Transaktion
* Liste mit den letzten Blöcken
* Liste mit den letzten Transaktionen
* Miner Steuerung
  * Aktiv / Inaktiv
  * Aktueller Status vom Miner
