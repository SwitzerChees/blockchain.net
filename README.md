# blockchain.net
A blockchain implementation based on the dotnet standard 2.0

## Projektidee
Die Idee dieses Projekts war es eine eigene Blockchain auf .NET Basis zu erstellen.

Das Angular Frontend soll folgendes enthalten:
* Anzahl Blöcke
* Anzahl Transaktionen
* Letzte Transaktion
* Liste mit den letzten Blöcken
* Liste mit den letzten Transaktionen
